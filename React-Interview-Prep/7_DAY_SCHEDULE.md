# 7-Day Interview Prep Schedule

## 📅 DAY 1: React 19 Fundamentals (4-5 hours)

### Morning (2 hours)
- [ ] Read React 19 overview
- [ ] Understand React Compiler concept
- [ ] Learn about Ref as prop (no forwardRef)
- **Code**: Create a simple component with ref prop

### Afternoon (2 hours)
- [ ] Study useActionState hook
- [ ] Study useFormStatus hook
- [ ] Build a login form with useActionState
- **Practice**: Create a form that submits data

### Evening (1 hour)
- [ ] Review and consolidate notes
- [ ] Create flashcards for key concepts
- [ ] Practice explaining to yourself

---

## 📅 DAY 2: React 19 Advanced Hooks (4-5 hours)

### Morning (2 hours)
- [ ] Study useOptimistic hook
- [ ] Study use() hook for promises
- [ ] Understand when to use each hook
- **Code**: Build an optimistic todo list

### Afternoon (2 hours)
- [ ] Review useContext, useReducer, useEffect
- [ ] Study custom hooks pattern
- [ ] Build a custom useFetch hook
- **Practice**: Create a data fetching component

### Evening (1 hour)
- [ ] Review Day 1 + Day 2 concepts
- [ ] Create a comparison chart of all hooks
- [ ] Practice explaining differences

## 📅 DAY 3: Server Components & Actions (4-5 hours)

- [ ] Build a form with server action

## 📝 Study Techniques

### 1. Active Recall
- Don't just read, test yourself
- Close the docs and explain concepts
- Answer questions without looking

### 2. Spaced Repetition
- Review Day 1 material on Day 3
- Review Day 2 material on Day 5
- Review Day 3 material on Day 7

### 3. Teach Others
- Explain concepts to a friend
- Write blog posts
- Record yourself explaining

### 4. Practice Coding
- Build small projects
- Solve coding challenges
- Refactor existing code

### 5. Create Flashcards
- Key concepts on one side
- Explanation on other side
- Review daily

## 🚨 If You Get Stuck

### Concept not clear?
1. Read the official docs
2. Watch a YouTube tutorial
3. Build a small example
4. Explain it to someone else

### Can't solve a problem?
1. Break it into smaller parts
2. Look at similar examples
3. Try a different approach
4. Ask for help (but try first!)

### Feeling overwhelmed?
1. Take a break
2. Focus on one topic at a time
3. Review what you've learned
4. Remember: you've got this! 💪
