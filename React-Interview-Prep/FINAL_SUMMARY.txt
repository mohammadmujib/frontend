🔥 TOP 10 THINGS TO KNOW:
================================================================================

1. Server Components by default
   → Use Client Components only for interactivity

2. useActionState for forms
   → Simplifies form handling with server actions

3. useOptimistic for UX
   → Update UI before server responds

4. Server Actions are secure
   → Keep sensitive logic on server

5. Middleware for auth
   → Protect routes with middleware

6. ISR for performance
   → Build static, revalidate on demand

7. Image optimization
   → Always use <Image> component

8. Error handling matters
   → Use error.jsx and not-found.jsx

9. Security first
   → httpOnly cookies, validate on server

10. React Compiler
    → Automatic optimization, no manual memoization
